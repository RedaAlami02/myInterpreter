# APIs and databases in use — 2026-11-17

Every external endpoint myInterpreter depends on, what it returns, and what is
known to break. Probes were run on 2026-11-17; shapes can change without notice.

## Casablanca Bourse (official site)

Base: `https://www.casablanca-bourse.com`

| Route | Content |
|---|---|
| `/live-market/actions` | Server-rendered page whose `drupal-settings-json` block contains `live_market.actions`: one row per listed instrument (symbol, `ce`, issuer, sector, status, open/high/low/last/reference, variation, volume, quantity, transaction count, capitalisation, share count, best bid/ask) |
| `/live-market/actions/cours?symbol=<sym>&ce=<ce>` | Instrument detail page. `live_market.action_data` carries `instrument_details` (isin, shares_count, nominal_value), `financials_details.chiffres` (annual rows), `financials_details.ratios`, `dividend_details`, `shareholders_details`, `capital_increase_details`, `threshold_details` |
| `/live-market/overview`, `/indices` | Index and market overview pages |

Gotchas:

- The TLS chain is incomplete. `tools/capture_exchange_pages.py` fetches the
  issuer certificate from the leaf's `CA Issuers` AIA URL, verifies it against
  system roots and builds a local bundle. Verification is never disabled.
- Pages are server-rendered JSON in HTML; no XHR/API call is needed.
- Only best bid/ask is published here — no order-book depth.

## Medias24 / LeBoursier

Base: `https://medias24.com/content/api?method=<method>&format=json&t=YYYY-MM-DD-HH:MM`

| Method | Content |
|---|---|
| `getAllStocks` | 76 instruments: `name`, `ISIN`, `slug`, `cotation`, `datetime`, price fields |
| `getBidAsk` | `orderBook`: **10 bid + 10 ask levels** (`bidValue/bidQte/bidOrder`, `askValue/askQte/askOrder`) |
| `getStockInfo`, `getStockIntraday`, `getStockHistory`, `getStockOHLC` | Quote and history |
| `getTransactions` | Trades |
| `getMasiInfo`, `getMarketIntraday`, `getSectorInfo`, `getSectorHistory` | Indices and sectors |
| `getBestPerformers`, `getWorstPerformers`, `getBasicStocksInfo` | Rankings, names |

Gotchas:

- Keyed by ISIN, not ticker. `public.format.isin` provides the mapping, filled
  by `exchange-orderbook-identities.yml` from the exchange capture.
- Returns **403 to GitHub Actions addresses** even with browser-identical
  headers. From ordinary networks it works. The order-book capture therefore
  falls back to CDG in the cloud and keeps Medias24 first in code.

## CDG Capital Bourse

`POST https://www.cdgcapitalbourse.ma/api/` with a JSON body:

```json
{"ACTIONS":[{"ACTION":{"NAME":"VALEUR-PROFONDEUR","TYPE":"SELECT","VALUE":"VALEUR-PROFONDEUR"},
 "PARAMS":[{"NAME":"Lang_","TYPE":"S","VALUE":"FR"},{"NAME":"Espace_","TYPE":"I","VALUE":"1"},
 {"NAME":"Symbol_","TYPE":"S","VALUE":"ADH"},{"NAME":"NumSeq_","TYPE":"I","VALUE":"0"},
 {"NAME":"Top_","TYPE":"I","VALUE":"10"}]}]}
```

| Action | Content |
|---|---|
| `TICKER` | 82 symbols with last price and variation |
| `VALEUR-SYNTHESE` | Quote: status, phase, OHLC, reference, volume, trades |
| `VALEUR-PROFONDEUR` | Depth: `Achat/QteAchat/NbrAchat/HeureAchat`, `Vente/QteVente/NbrVente/HeureVente` (10–20 levels) |
| `VALEUR-TRANSACTIONS` | Trades |
| `VALEUR-GRAPH-APPL` | ~3 years daily OHLC and volume |
| `VALEUR-SESSIONS` | Recent sessions |
| `INDICE-SYNTHESE` | Index rows |

Gotchas: responses are keyed by action name only and do not echo the symbol, so
depth is captured one symbol per request. Quotes are delayed; treat the
freshness class as `DELAYED`.

## Wafabourse

Same action API over a browser session. Not usable in cloud automation without
a browser. Kept as a research cross-check only.

## Supabase

PostgREST at `https://<project>.supabase.co/rest/v1`. The publishable key is
used by the site; the service key (`sb_secret_…` or a legacy JWT) is sent as
`apikey` only — sending `sb_secret_…` as a Bearer token returns 401.

### Write RPCs (service role)

| RPC | Purpose |
|---|---|
| `apply_exchange_latest_prices(p_snapshot text, p_snapshot_sha256 text)` | Current price per company into `latest_prices`; validates digest, mapping, share-count consistency and older-than-current |
| `apply_exchange_history(p_snapshot text, p_snapshot_sha256 text)` | One `public.data` row per company and trading day; PER/P-B from capitalisation with legacy guards |
| `apply_exchange_dividends(p_snapshot text, p_snapshot_sha256 text, p_years integer[])` | Combines components into one row per company and payment year |
| `apply_exchange_orderbooks(p_snapshot text, p_snapshot_sha256 text, p_prune boolean)` | Changed-only order books; validates ordering and freshness |
| `prune_exchange_orderbooks(p_intraday_days integer, p_daily_days integer)` | Retention wrapper (7/400 by default) |
| `apply_instrument_identities(p_snapshot text, p_snapshot_sha256 text)` | Ticker → ISIN into `public.format` |
| `apply_exchange_share_reconciliation(...)` | Verified share counts (serialised per company) |
| `stage_exchange_annual_candidates`, `apply_exchange_annual_candidates`, `reject_exchange_annual_candidates`, `read_exchange_annual_candidates` | Annual-review queue |
| `admin_update_company(p_name text, p_fields jsonb)` | Reviewed company updates with guards |

### Read RPCs

`read_latest_price_references_v1`, `read_recent_market_sessions`,
`read_price_company_context(_recurring_v1)`, `read_shadow_market_feed(_recurring_v1)`,
`read_shadow_application_feed(_recurring_v1)`, `read_enrichment_context(_recurring_v1)`.

### Tables (public)

`company`, `format`, `data`, `latest_prices`, `dividends`, `market_orderbooks`,
`company_profiles`, `market_snapshots`, `market_reference`,
`dividend_source_snapshots`.

Audit and maintenance objects live in `market_maintenance` and are not exposed
through PostgREST except through the RPCs above.
